# World Wide Importers Dashboard w/ Power BI

## 💡 Introduction

World Wide Importers is an e-commerce company based in the USA. They sell goods from different industries like IT, Sports, and Office Supplies. 
This dashboard helps the company's executives make data-driven decisions.

## 🗝 Key Business Questions Answered

* How does the company perform compared to PY (Prior Year)?
* Which buying group generates the highest revenue?
* Do we notice any seasonal trends throughout the year?
* What are the Net Profit Margin and AOV (Average Order Value)?
* Which product generates the highest revenue?
* Which salesperson performs the best?
* How does our performance differ across regions?

## 🛠 Skills Showcased

This project put key Power BI features into practice. Here's what was mastered:

* **🎨 Dashboard Design:** Crafting an intuitive and visually appealing report layout (UX-oriented).
* **⚙️ Power Query ETL:** Performing data cleaning, shaping, and transformation.
* **🔗 Data Modeling:** Building efficient data models with relationships (Star Schema). Creating a `dim_date` table using DAX (`CALENDARAUTO()`).
* **🧮 DAX Fundamentals:** Creating calculations and aggregations to derive key insights (e.g., `CALCULATE()`, `SAMEPERIODLASTYEAR()`, `SWITCH()`, `DATEADD()`, `SUM()`, `SUMX()`, `RELATED()`, `USERELATIONSHIP()`).
* **📊 Visualizations Utilized:**
    * **📈 Core Charts:** Column, Bar, and Line charts for comparisons and trends.
    * **🗺️ Map Charts:** For displaying geospatial data.
    * **🔢 Cards:** To highlight key performance indicators (e.g., CY vs. PY Profit KPI).
    * **📋 Tables:** For presenting detailed, tabular information.
    * **🎨 Chart Variety:** Selecting from common and uncommon chart types for effective storytelling.
* **🖱️ Interactive Features:**
    * **🎚️ Slicers:** Enabling dynamic, user-driven data filtering.
    * **⚙️ Parameters:** Enabling dynamic metric on the visuals (Revenue/Profit).
    * **🔘 Buttons & Bookmarks:** For streamlined navigation and managing filter pane visibility.

## 🧠 Conclusion

This Dashboard showcases Power BI's ability to transform raw sales data into a powerful, streamlined tool for company performance analysis. It empowers corporate executives by allowing them to filter and explore essential sales trend insights efficiently across three different pages, helping them make data-driven decisions about their next business moves.
